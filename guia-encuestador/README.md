# Guía del encuestador/a: Censo Comunitario El Carmen

Fragmentos extraídos del *Formulario Censo El Carmen v27* para que el equipo de campo los tenga a mano mientras aplica el formulario en KoboCollect.

| Archivo | Uso |
|---|---|
| `guia_encuestador_censo_el_carmen.html` | Copiar al celular Android y abrir con Chrome. Funciona sin internet y tiene un buscador (ej.: «Kayambi», «jornalero», «470»). |
| `guia_encuestador_censo_el_carmen.pdf` | Versión corta para imprimir en A4 (7 páginas). Varias tarjetas por hoja, listas para recortar y enmicar. Omite los catálogos que ya están en KoboCollect. |

## Contenido

1. Consentimiento informado (texto completo para leer en voz alta)
2. Definición de hogar y preguntas de sondeo
3. Catálogos de las Matrices A, B, C y D (completos solo en la versión para celular)
4. Códigos cortos de migración y cultivos (solo en la versión para celular)
5. Tarjetas de respuesta para mostrar al informante: rama de actividad, categoría de ocupación y sitio de trabajo (Matriz C), y preguntas 31, 34–35, 40, 41, 59, 62, 66, 68, 69 y 70
6. Flujo del formulario (saltos)
7. Texto de cierre

Para regenerar el PDF después de editar el HTML, imprima la página desde Chrome (A4, con gráficos de fondo).
